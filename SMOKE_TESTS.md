# Demo Bank — Smoke Test Checklist

## Login Page
- [ ] Page loads without errors
- [ ] Username and password fields are visible
- [ ] Login button is clickable
- [ ] Valid credentials redirect to dashboard

## Dashboard
- [ ] Shows account balances
- [ ] Shows recent transactions

## Transfer
- [ ] Can select accounts
- [ ] Can enter amount and submit

---

*Note: This checklist is intentionally incomplete. A proper smoke test suite should also cover:*
*error states, logout flow, session management, edge cases, and security scenarios.*
