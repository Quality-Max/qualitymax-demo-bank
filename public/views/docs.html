API Documentation

Authentication

All API endpoints require session authentication. Login first:

POST /api/login
Content-Type: application/json

{ "username": "demo", "password": "demo123" }

Endpoints

MethodPathDescription
POST/api/loginAuthenticate and get session cookie
POST/api/logoutEnd session
GET/api/meGet current user profile
PUT/api/meUpdate user profile
GET/api/accountsList user accounts
GET/api/accounts/:idGet account details
GET/api/transactionsList transactions (query: account_id, search)
POST/api/transferTransfer money between accounts
GET/api/admin/usersList all users (admin only)
GET/api/healthHealth check

Transfer Example

POST /api/transfer
Content-Type: application/json
Cookie: session=YOUR_SESSION_TOKEN

{
  "from_account_id": 1,
  "to_account_id": 2,
  "amount": 100.00,
  "description": "Monthly savings"
